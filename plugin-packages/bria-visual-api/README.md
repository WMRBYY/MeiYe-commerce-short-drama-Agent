# Bria Visual API

Generated from Bria's official OpenAPI bundles. Each supported visual POST operation has its own declarative protocol. Authentication uses the `api_token` header. v2 jobs poll `/v2/status/{request_id}`. Advanced operation-specific fields are supplied through `providerOptions.<protocol-id>.body`. The imported models remain disabled until pricing and availability are configured.

Source: https://docs.bria.ai/
